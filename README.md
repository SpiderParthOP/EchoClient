## 🚀 About

**Echo Launcher** is a powerful Minecraft launcher inspired by Feather, Lunar, and Badlion – designed with both **performance** and **customization** in mind. Whether you're on Android or desktop, Echo gives you the tools to mod, optimize, and play Minecraft your way.

---

## 🎯 Key Features

- ✅ Multi-platform support (Android, Windows, Linux, macOS)
- 🔧 Built-in **Forge Installer** for mods
- 📦 Modpack installer support
- 🌐 DNS Injector for competitive optimization (Android)
- 🎮 Based on Pojav + custom enhancements
- ⚙️ Future-ready Mod Browser UI (coming soon)
- 💡 Feather-style UI and launcher experience
- 🔥 Clean, minimal design – no bloat!
